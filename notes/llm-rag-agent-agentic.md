# LLM vs RAG vs AI Agent vs Agentic AI

![LLM vs RAG vs AI Agent vs Agentic AI — the four layers of intelligence](../image-1.png)

**The Layers of Intelligence in AI Systems.** Each layer builds on the one
below: **understand → ground → act → orchestrate.**

> Source: diagram "LLM vs RAG vs AI Agent vs Agentic AI." Reproduced here as
> text. See the companion map [Agentic AI: A Complete Framework](./agentic-ai-framework.md).

## The four layers at a glance

| Layer | = | What it does |
|-------|---|--------------|
| **1. LLM** | Language | Understands and generates human-like text. |
| **2. RAG** | Grounding | Retrieves and grounds responses in external, trusted data. |
| **3. AI Agent** | Execution | Uses tools, memory, and planning to take action and get work done. |
| **4. Agentic AI** | Orchestration | Coordinates multiple agents and systems autonomously toward goals. |

## Layer 1 — LLM (Large Language Model)

- Parametric knowledge
- Prompt Engineering
- Few-shot / Zero-shot Learning
- Chain-of-Thought reasoning
- Attention Mechanism
- Tokenization
- Text Generation

See: [How Language Models Work](../generative-ai/02-how-llms-work.md) ·
[Prompt Engineering Basics](../generative-ai/05-prompt-engineering.md).

## Layer 2 — RAG (Retrieval Augmented Generation)

- Custom knowledge base integration

- Query Reformulation
- Similarity Scoring
- Retrieval Pipelines
- Document Chunking
- Source Attribution
- Context Injection
- Index Management
- Grounded Answer Generation
- Metadata Filtering

See: [Context, Memory & Limits](../generative-ai/04-context-and-memory.md).

## Layer 3 — AI Agent (Tool-based Execution)

- Planning & Execution

## Foundation: Intelligent Systems (all four layers)

Five pillars underpin every layer:

1. **Security & Access Control**
2. **Governance & Compliance**
3. **Observability & Monitoring**
4. **Evaluation & Testing**
5. **Human Oversight & Trust**

## The evolution

```
LLM  →  RAG  →  AI Agent  →  Agentic AI
Language  Grounding  Execution  Orchestration
```

> **How to read this map:** each layer builds on the one below it. Together,
> they enable systems that can understand, find, act, and autonomously achieve
> goals.

## Recap

- **LLM** = understand · **RAG** = ground · **Agent** = act · **Agentic AI** =
  orchestrate.
- Each layer adds a capability; the five foundation pillars (security,
  governance, observability, evaluation, human oversight) support all of them.
- Match your system to the layer you need — don't jump to Agentic AI before
  grounding and execution are solid.
